# Digital Clock using Verilog

## Description

This project implements a simple **24-hour Digital Clock** using Verilog HDL.

The clock counts:
- Seconds (0–59)
- Minutes (0–59)
- Hours (0–23)

## Features

- Reset functionality
- Automatic second, minute, and hour increment
- 24-hour clock format
